Smart Industrial Inspection Robot

Prototype complete

STM32 + RK3568 mobile inspection platform · ROS navigation

Role
Team lead · Power design · Chassis firmware · Integration
Period
2026.04 – 2026.08
Stack
STM32F407 · FreeRTOS · TB67H451FNG · RK3568 · ROS
  • Designed the whole-vehicle power chain (intake, step-down, distribution) plus the motor driver board, STM32 core board and power control board: schematics and PCB with reverse-polarity protection, overvoltage protection, soft start, and power/signal isolation.

STM32F407 Bootloader & A/B OTA

Stable

Dual-bank bootloader with USB CDC firmware update · STM32F407

Role
Independent development
Period
2026.01 – 2026.02
Stack
STM32F407 · Bootloader · USB CDC · CRC32 · ESP32-S3
  • Built a custom firmware transfer protocol over USB CDC: packet reception, ordered buffering, partition writes, status feedback and error responses, with CRC32 integrity checks.
  • Implemented on-demand sector erase by checking sector state, reducing Flash wear; designed a seven-stage state machine covering wait, erase, receive, write, verify, jump and recovery.
  • Added receive timeout, watchdog reset and write-error detection with automatic rollback on failure; handled Flash address offset, vector table relocation, stack initialization and stable jump to the application. Recorded upgrade success rate: 100%.
